      📖 Kullanım Kılavuzu

      1. Başlangıç & API Kurulumu

      KuCoin API anahtarlarınızı proje kök dizinindeki .env dosyasına girin (KUCOIN_API_KEY, KUCOIN_API_SECRET, KUCOIN_API_PASSPHRASE). Güvenlik: API anahtarında kesinlikle "Para Çekme (Withdraw)" yetkisi vermeyin. Yalnızca "General" (okuma) ve "Spot/Trade" (işlem) yetkileri yeterlidir.

      2. İşlem Modları

      🧪 SIMULATION (Paper Trading): Canlı tahta fiyatıyla eşleşen, $10,000 sanal USDT ile çalışan, bakiye düşümünü gerçekçi simüle eden sıfır riskli test ortamı. Varsayılan moddur.

      ⚡ LIVE KUCOIN: Gerçek hesabınızdan gerçek emir iletir. Sadece stratejinizi simülasyonda test ettikten sonra kullanın.

      3. Analiz Göstergeleri

      Bileşik Skor (0-100): Trend, momentum, güç, hacim ve yapı katmanlarından ağırlıklı boğa/ayı puanı. ≥80 güçlü sinyal, 60-80 normal sinyal, altı nötr.

      MTF (Multi-Timeframe): 4H rejim → 1H kurulum → 15m tetikleyici hiyerarşisi. Üç zaman dilimi uyumlu olmadan işlem önerilmez.

      SMC (Market Structure): BOS (yapı kırılımı), CHoCH (karakter değişimi), FVG (fiyat boşluğu) gibi kurumsal fiyat hareketi kavramları.

      4. Emir Verme

      Market: Anlık fiyattan hızlı al/sat. Limit: Belirlediğiniz hedef fiyattan. Bakiyenizden fazla emir engellenir (pre-trade risk kontrolü).

      5. Panic Stop 🛑

      Acil durumda tek tıkla tüm açık emirleri iptal eder ve botu durdurur. Bot durunca yeni emir kabul edilmez; tekrar başlatmak için mod değiştirin.
